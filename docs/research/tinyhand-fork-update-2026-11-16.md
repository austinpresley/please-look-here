## New useful ideas

These numbers identify this week's ideas. They do not replace the 14 November selection numbers or authorize implementation.

1. **Remember an ink color for each pointer. Consider later.** [Waypointer commit `fe00f7ce`](https://github.com/Felitendo/waypointer/commit/fe00f7cef13175d2cfb0cc7d2bfce78dd3385294) stores an optional color under each pointer ID and restores the pointer's own color when cleared. The final source routes the global matching-color mode through that override. This would let a favorite hand consistently draw in a preferred color. Our current per-pointer configuration covers size, shadow and sound; drawing has a global color choice and the hand's built-in/custom metadata color, but no user override for each catalog pointer. **Medium effort and moderate compatibility risk.** Extend our existing configuration, import/export validation and controls deliberately. Retain the global fixed-color override and use an explicit Use Default action. The donor automatically switches global ink to Match when editing a pointer; that side effect deserves a separate UX decision here. This is a portable idea from a **Linux-only implementation**, not working Mac donor code. Sources: [resolution and reset](https://github.com/Felitendo/waypointer/blob/7d83196e43e30a25d3623a3f31c63834440161f3/src/hub.rs#L214-L247), [saved map](https://github.com/Felitendo/waypointer/blob/7d83196e43e30a25d3623a3f31c63834440161f3/src/settings.rs#L58-L63), [chooser](https://github.com/Felitendo/waypointer/blob/7d83196e43e30a25d3623a3f31c63834440161f3/src/ui.rs#L459-L498), [local configuration](../../Sources/TinyHand/PointerConfiguration.swift), [local customization](../../Sources/TinyHand/PointerCustomization.swift).

2. **Adjustable click emphasis, with automatic rapid-click buildup. Defer.** [PlayPointer commit `4848529c`](https://github.com/omiusgm/playpointer/commit/4848529c1bf5b1a2f7567b8c70df51823789f782) adds five global strengths and increases visual emphasis when primary clicks arrive less than 650 ms apart. It changes press compression, ring size and special effects, not audio volume. Our optional Tap Swing already controls tap exaggeration, so this adds refinement rather than a missing core behavior. **Medium effort and moderate integration risk**, chiefly contact timing, cancellation, Reduce Motion and the live preview. If selected later, keep it optional and preserve current defaults. The donor has no Off strength. Basic click rings were already reported as C16 on 9 November; only strength scaling and cadence are new here. Sources: [strength/cadence](https://github.com/omiusgm/playpointer/blob/cb95a7cc00d7a6e510023b179ec136b2005a3873/Sources/TinyHand/ClickExpression.swift#L3-L44), [feedback wiring](https://github.com/omiusgm/playpointer/blob/cb95a7cc00d7a6e510023b179ec136b2005a3873/Sources/TinyHand/OverlayController.swift#L521-L552), [scaled rings](https://github.com/omiusgm/playpointer/blob/cb95a7cc00d7a6e510023b179ec136b2005a3873/Sources/TinyHand/ClickPulse.swift#L63-L102), [our Tap Swing](../../Sources/TinyHand/TapSwing.swift).

3. **Squash and rebound while keeping the fingertip fixed. Reference only.** [PlayPointer commit `cb95a7cc`](https://github.com/omiusgm/playpointer/commit/cb95a7cc00d7a6e510023b179ec136b2005a3873) adds a 180 ms comic reaction and black/white impact strokes. Its renderer recomputes the grip after deformation so the fingertip stays on the target, including near the lower screen edge. That geometry is useful for a future original animated hand. It is not evidence of a local hotspot bug. **Medium effort and moderate rendering risk**, because our contact shadow, gesture poses, swing and sound scheduler must remain coherent. Use original art if prototyping: the donor README explicitly separates the Pokey author's artwork rights from the code's MIT license. Sources: [anchored geometry](https://github.com/omiusgm/playpointer/blob/cb95a7cc00d7a6e510023b179ec136b2005a3873/Sources/TinyHand/ArmView.swift#L586-L645), [impact strokes](https://github.com/omiusgm/playpointer/blob/cb95a7cc00d7a6e510023b179ec136b2005a3873/Sources/TinyHand/ClickPulse.swift#L7-L60), [donor attribution](https://github.com/omiusgm/playpointer/blob/cb95a7cc00d7a6e510023b179ec136b2005a3873/README.md#L48-L50).

The final PlayPointer catalog exposes **four** new choices: cream hand, mint cheeky hand, coral arrow and comic hand. The earlier paw PNG remains packaged but its catalog entry was replaced, so it is not a fifth selectable pointer. I would skip the new artwork for now. The coral arrow is a standalone sprite, distinct from our already implemented telescoping Presentation pointer. Sources: [final catalog](https://github.com/omiusgm/playpointer/blob/cb95a7cc00d7a6e510023b179ec136b2005a3873/Sources/TinyHand/PointerStyle.swift#L10-L43), [retained paw asset](https://github.com/omiusgm/playpointer/blob/cb95a7cc00d7a6e510023b179ec136b2005a3873/assets/hand_presenterPaw.png).
