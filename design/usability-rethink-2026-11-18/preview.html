Design decisions and implementation notes
  • Keep the pointer visibility control independent. Replace the inverted Interact switch with Use apps / Draw. Show a selected segment and a clear pointer on/off state. Tool choices remain visible only in Draw.
  • One ordered Favorites list feeds menu controls, toolbar and Quick controls. Preserve the toolbar's eight-item capacity. The radial uses the first six plus All pointers. Preview any migration from today's separate saved lists before applying it.
  • Keep every existing pointer. Selecting a tile changes the current pointer; its star changes Favorites only. Search never changes the current selection. Missing artwork needs a restore action, not a blank selectable tile.
  • Combine the library, current preview and everyday adjustments in Pointers. This pointer / Pointer defaults names the scope. Each overridden value has its own Use default arrow. Motion and master volume remain app-wide under General, never in a per-pointer scope.
  • Advanced hand gestures, artwork and import remain available through More adjustments. New hand uses a sheet. Presets, backups, shortcut assignment and About remain reachable.
  • Practice starts in a local canvas. Ask for Accessibility when drawing on the desktop is requested, and Screen Recording when capture or magnification is first used. The prototype does not request permissions or control your desktop.
  • Use SF Symbols in the native implementation. Every icon needs a tooltip, accessible name and keyboard access. Keep Use apps / Draw and setting names visible because those icons need context. These drawings are proposals, not usability test results.
  • Before images are native captures. Menu controls were captured from the local review app on 18 November. Pointers and Customize use the latest native Settings captures from 18 November. The welcome before is a reconstruction of the current source, with the current hand artwork.

Primary references: Apple buttons, offering help, sheets. App behavior and friction are assessed from this checkout.
