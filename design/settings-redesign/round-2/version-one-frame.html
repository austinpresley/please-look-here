    Opus review and design decisions

    Opus 5.5 reviewed all eight pages and their supporting code at high effort. It independently identified split defaults, live controls presented as preferences, a crowded pointer library, long shortcut lists, interlocked screenshot switches and misplaced reset/update actions.

    • Adopted: seven pages; Effects absorbs Sound; Controls owns keyboard, toolbar, Quick controls and Stream Deck; status-first permissions; one screenshot outcome choice; readable preset summaries.
    • One owner for favorites: Opus proposed two favorite strips in Pointers. This proposal places both editors in Controls, with a direct link from Pointers, so the library stays focused on choosing a pointer.
    • Keep combined filters: a single Filter menu replaces the visible filter controls while retaining combinations. It does not restrict people to one filter at a time.
    • Keep scopes explicit: Effects previews shared defaults. Customize edits one pointer. Mute controls all app output. Turning shadow off preserves the previous style, and resetting one override preserves the others.
    • Keep help where it matters: permissions, master mute, shortcut scope and import consequences remain visible. Longer tutorials belong in Practice or an optional disclosure.
    • Do not grow Effects into another long form: sound details, lens settings and motion tuning have named disclosures. Remember their open state and automatically reveal a linked setting.

    Opus also suggested an Apply Preset menu command and more selective settings refreshes. Those are follow-up implementation ideas, outside the proposed page layouts.

    Implementation order and acceptance checks
    1. Move existing controls into the seven destinations. Preserve old section identifiers as redirects, including shortcuts → Controls, appearance → Effects, and sound → Effects / Sound. Keep practice links and external control requests working.
    2. Rebuild the pointer library and sheets. Reuse its content in the standalone pointer chooser. Keep visible labels, keyboard actions, missing-artwork recovery and Undo Remove.
    3. Replace screenshot booleans with a three-choice interface backed by the existing two values. Preserve the current folder when Copy to clipboard hides it.
    4. Finish the copy and conditional states: granted/denied permissions, missing update feed, sound muted, pointer overrides, import conflicts, empty library and empty presets.
    5. Verify locally on Austin's Mac. Cover all seven pages and both sheets in light and dark, keyboard and VoiceOver, resize/long labels, shortcut routing and independent override resets. Keep hosted CI disabled.

    Settings should reopen on the last page. Use native macOS controls and one scroll area per page. Applied settings take effect immediately; only save/import/create tasks need confirmation buttons.
