Next enabled pointer

Each press chooses the next enabled, available pointer in Look Here Please, then wraps to the first. All choices are included, even unpinned and custom hands.

Cycling keeps On/Off and Interact unchanged. Use Pointer On/Off to turn an off pointer on.

The key shows the current pointer acknowledged by the app. Enable choices in Settings > Pointers.

Rapid presses wait in order. If a reply is lost, Check app marks the uncertain result. That press is never repeated. Unsent presses continue after status recovers. Leaving the key's page cancels unsent presses.

Keep Look Here Please running to use this key. Use Select Pointer for a fixed choice.
